# ValidoHub

ValidoHub is the first real site project generated by Valido Engine.

This repository contains content and configuration only. It does not contain Valido Engine source code, runtime services, database code, or algorithm implementations.

## Structure

- `site.yaml` defines the site configuration.
- `categories/` defines tool categories.
- `countries/` defines country hubs.
- `tools/` defines tool metadata and algorithm bindings by `algorithmId`.
- `content/tools/` contains localized Markdown content blocks.
- `locales/` is reserved for future locale-specific content/configuration.

## Validation

Run Valido Engine against this project:

```bash
engine doctor --site site.yaml
```

The initial project is intentionally in demo mode while real algorithm implementations are added later.
