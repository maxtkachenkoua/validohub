# Polish Company Onboarding Auditor examples

## Validate a single value

Paste a value or record into the workbench and run **Validate** to see format checks, normalized output, masking, and a detailed diagnostic pipeline.

## Batch review

Paste multiple rows into batch mode to inspect lists before imports, support tickets, migrations, or QA fixtures.

## Safe fixture generation

Use **Generate** to create fictional, non-production examples for tests, documentation, and demos. Generated values are for local development and must not be treated as official identifiers.
