# ValidoHub AI Operating System

`docs/ai/` exists so future AI assistants can continue ValidoHub development without relying on chat history.

This directory is the permanent AI-facing operating layer for the project. It explains how to read the Product Bible, how to preserve architecture boundaries, how to validate work, and how to record decisions. The goal is simple: ValidoHub should remain understandable years later, even if the original conversation context is gone.

Start every AI session with `START_HERE_AI.md`.
