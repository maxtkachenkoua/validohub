# Global Premium Tools Batch 4-7

This batch adds 20 browser-only global premium workbenches across four product categories:

- Batch 4 Cloud / DevOps: Kubernetes YAML Inspector, Dockerfile Auditor, GitHub Actions Workflow Inspector, Terraform Plan / HCL Inspector, NGINX / Apache Config Inspector.
- Batch 5 AI / Data / RAG: Prompt Injection Scanner, RAG Chunking Workbench, Vector Metadata Schema Inspector, JSONL Fine-Tune Dataset Inspector, Eval Dataset Builder.
- Batch 6 Backend / API: REST Error Contract Inspector, Idempotency Key Workbench, Rate Limit Header Inspector, CORS Policy Workbench, WebSocket / SSE Message Inspector.
- Batch 7 Frontend / QA: HTML Meta / SEO Inspector, Accessibility Snapshot Inspector, Design Token Inspector, Source Map / Stack Trace Parser, Browser Storage Inspector.

All tools use the global premium shell: browser-only analysis, success/review samples, immediate result preview, validation pipeline, field breakdown, quality notes, Developer API preview, and snapshot JSON. The analyzers are static and do not execute cloud plans, CI workflows, Docker builds, Kubernetes manifests, prompts, API calls, HTML, or browser-state payloads.
