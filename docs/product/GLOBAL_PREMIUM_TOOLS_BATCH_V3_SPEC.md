# Global Premium Tools Batch V3

Batch V3 adds 15 browser-only global workbenches grouped for product planning:

- Web/API Quality: CSP Builder & Auditor, URL Redirect & UTM Workbench, HTTP Request / Response Diff Inspector.
- Data & Integration: JSONPath / JMESPath Workbench, Avro / Protobuf Schema Inspector, NDJSON / Log Parser Workbench, Diff / Patch Workbench, Base64 / Binary Payload Inspector.
- Security / Ops Premium: JWT / JWK / OAuth Token Inspector, Cookie Security Inspector, Secret Scanner Workbench, TLS Certificate Inspector, DNS Record Workbench, SPF / DMARC Builder, SRI Hash & Integrity Inspector.

All tools use the shared generic-suite premium shell, local analyzers, success and review samples, result cards, validation pipeline, field breakdown, quality notes, Developer API preview, and Developer snapshot JSON. Live DNS, TLS chain validation, OAuth introspection, endpoint calls, and remote asset fetching remain explicit boundaries.

The shared global advanced-analysis layout now constrains grids, cards, and code blocks inside the accordion to prevent page-level horizontal overflow on desktop and mobile.
