# Spain Premium Country Suite V1

Spain Premium Country Suite V1 upgrades Spain from two standalone country tools into a full Country Suite Factory V1 implementation. It preserves the existing /spain/spain-id-validator/ and /spain/spain-iban-validator/ routes while adding a broad browser-only suite for Spanish identity, tax, banking, payments, e-invoicing, locale, privacy, document, vehicle, postal, and developer-data workflows.

## Scope

- 60 active Spain-specific workbenches.
- Shared runtime: `assets/js/tools/spain-suite.js`.
- Shared algorithm metadata: `validohub.spain-suite`.
- Factory dependency: `assets/js/tools/country-suite-factory.js`.
- Country hub data: `countries/data/spain.json`.

## Quality Bar

Spain follows the Poland/Brazil presentation baseline and the Country Suite Factory V1 contract: compact tool headers, short sample labels, immediate results, validation pipeline, dedicated field breakdowns, quality notes, advanced analysis, browser-only boundaries, and runtime localization for the configured production locales.

## Official Boundaries

Offline browser checks do not prove official status. AEAT, VIES, TGSS, DGT, Correos, banks, payment providers, and other responsible Spanish systems remain the source of truth for regulated status, ownership, filings, payments, delivery, vehicle records, and legal identity.
